# Word-book data

Each JSON file is a self-contained word book. Its top-level `id` must match each
word's `book`, and every word `id` must remain stable so saved progress,
favorites, and study logs continue to refer to the same entry.

The entries in this prototype were written for EasyWord and are not copied from
commercial vocabulary books or third-party dictionary datasets. Exam-related
books are topic-based starter sets, not official or complete exam lists. They
currently contain a small sample of words; use licensed sources and record their
exact attribution and license before importing a larger external dataset.
